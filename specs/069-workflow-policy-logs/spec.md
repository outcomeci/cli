# Workflow policy execution logs

Make proposals, advisor decisions/reasons, static denials, and execution results
visible in workflow execution logs. Record redacted durable broker events with
stable UUIDs; transport batches on the existing fenced listener heartbeat after
registration capability negotiation. Preserve event order, idempotence, phase,
and severity. Capture final events for both successful and failed execution.
Never upload credentials or raw request/response bodies. Old API compatibility
must retain local evidence without invalidating an otherwise healthy lease.

Validate allow/revise/deny, privacy, wrong lease rejection, duplicate upload,
final flush, transient transport failure, and existing execution behavior.
